# @fluxeaze/frontend

Next.js 16 (App Router) + React 19 + TypeScript (strict) + Tailwind CSS 4.

All setup, commands and the API-contract workflow are documented in the
[repository README](../../README.md). Backend integration status and
assumptions live in [BACKEND_INTEGRATION_REPORT.md](../../BACKEND_INTEGRATION_REPORT.md).

Quick start (from repo root): `npm install` → `cp apps/frontend/.env.example
apps/frontend/.env.local` → `npm run dev` (http://localhost:3000).
